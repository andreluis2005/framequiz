# 🎮 FrameQuiz

**O quiz interativo do Farcaster que recompensa com NFTs na Base!**  
Teste seus conhecimentos Web3 e ganhe tokens de conquista por respostas corretas.

👉 **Demo Online**: [framequiz.vercel.app](https://framequiz.vercel.app)  
📌 **Hackathon**: Base Batches LATAM 2025

![Banner do Projeto](https://raw.githubusercontent.com/seu-usuario/framequiz/main/public/banner.png)

## ✨ Funcionalidades
- ✅ Quiz diário via **Farcaster Frames**
- 🏆 **NFTs de recompensa** mintados na Base
- 📊 Leaderboard on-chain (contrato inteligente)
- 🔔 Notificações no Farcaster para retorno dos usuários

## 🛠️ Tecnologias
| Tecnologia       | Uso                          |
|------------------|------------------------------|
| MiniKit          | Integração com Farcaster     |
| Next.js          | Frontend responsivo          |
| Solidity         | Contrato de NFTs e scores    |
| Vercel           | Hospedagem e deploy          |
| Base             | Blockchain de execução       |
